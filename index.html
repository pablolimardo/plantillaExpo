El agua del tanque, bajo control

Un sensor mide el nivel, el Arduino lo lee y Python decide cuándo prender la bomba.

Ver el panel en vivo

El problema

En muchas casas de El Calafate el tanque se vacía sin aviso o rebalsa, y se desperdicia agua. Nadie se entera hasta que abre la canilla.

Cómo funciona

📡

1. Sensor

El HC-SR04 mide la distancia hasta el agua.

🧠

2. Arduino

Lee el sensor y envía el dato por USB con Firmata.

🐍

3. Python

Decide y activa el relé que prende la bomba.
